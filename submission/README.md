# Финальный классификатор C

Кандидат C — независимый пятифолдовый Qwen3.5-4B LoRA-ансамбль. Он использует
зафиксированные пороги `0.2123` для БАД и `0.717` для легковоспламеняющихся
товаров. Модель обучена на официальной разметке и на дополнительно вручную и с
помощью Qwen проверенных контрастных примерах.

После получения бинарного вердикта отдельный детерминированный renderer строит
обоснование. Он ищет в названии и описании точную опору, сопоставляет её с
правилом категории и формулирует контраст с ближайшим отрицательным или
положительным случаем. Обоснование не подменяет решение классификатора и не
может изменить метку.

Для БАД renderer различает прямую маркировку, явное отрицание и спортивное
питание. Для легковоспламеняющихся товаров он различает самостоятельный
источник огня, горючее содержимое, отдельный предмет в комплекте, встроенный
источник, пустую ёмкость и лишь совместимое, но отсутствующее топливо. При
недостаточной опоре вывод остаётся осторожным и не выдумывает визуальные факты.

Формат ответа ограничен 50–300 символами. Полный статический аудит охватывает
18 728 сочетаний официальных карточек и возможных вердиктов.
